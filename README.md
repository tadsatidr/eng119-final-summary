# Eng 119 (01355119) – final exam prep

Static study site for the KU 01355119 Foundation English final exam (35 points). It follows the official Final Examination Outline: Skimming & Scanning (6), Understanding Paragraphs (7), References/Substitution/Ellipsis (7) and Reading Comprehension (15).

Pure HTML/CSS/JS, no build step. Open `index.html`, or publish on GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / root.

Files: `index.html`, `style.css`, `script.js`, `.nojekyll`.
